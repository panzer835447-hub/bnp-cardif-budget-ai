# 法國巴黎人壽黑客松｜AI 預算預測與差異分析助手

透過歷史預算、每月實際支出與目前執行情況，自動分析預算差異、預測年底是否超支或執行落後，並由 AI 產生摘要與預警訊息，協助管理者提前調整資源配置。

## 功能對應題目要求
| 題目要求 | 系統功能 |
|---|---|
| 比較預算與實際支出差異 | 預算分析 → 差異長條圖、每月差異熱力圖 |
| 分析預算使用率 | 總覽「預算水位」、使用率頁（同期執行率） |
| 分析歷史預算執行情況 | 歷年預算 vs 實際、各年度執行率、預測回測 |
| 預測年底預算執行結果 | 55% 歷史季節性 + 45% Run-rate，附回測 P80 合理區間 |
| 提醒可能超支或執行落後 | 四色燈號、預警卡片、門檻可調 |
| 產生預算分析摘要與預警訊息 | AI 摘要（Gemini／Groq／OpenRouter／Ollama 自動接力）、報告下載 |

其他：情境模擬與預算調撥建議、成本歸因與重複費用偵測、CSV 匯入與防呆檢核（可對接 ERP 匯出檔）、AI 對話查詢、中英文與深淺色。

## 資料說明
內建資料為**競賽展示用合成資料**，量級依可調整的營業費用總額拆分，並埋入保險業常見情境（年底集中支出、一次性 CAPEX、專案超支／延宕）；不代表任何公司的實際數據。`測試資料/` 內有可上傳測試的 CSV。

## 本機執行
```bash
pip install -r requirements.txt
python -m streamlit run app.py
```
若電腦已安裝 Ollama 並下載 `qwen2.5:7b`，AI 助理會自動使用本機模型。
